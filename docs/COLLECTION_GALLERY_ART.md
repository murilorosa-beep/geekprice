# Arte da galeria de coleções

- Arquivo utilizado: `public/collections/collector-binder-hero.webp` (2073 × 758, aproximadamente 271 KB).
- Ferramenta: habilidade `imagegen`, modo integrado `image_gen`; sem CLI ou API externa configurada no aplicativo.
- Uso: banner e detalhes decorativos dos álbuns da página de coleções. As artes decorativas não são fotos dos itens cadastrados. Capas fornecidas pelo usuário têm preferência nos itens.
- Os textos, indicadores, barras e controles são HTML/CSS com dados reais. As barras dos álbuns representam unidades próprias / total de unidades cadastradas naquela categoria, incluindo desejos e compras pendentes no denominador.
- A primeira composição foi recusada pela ferramenta. A composição final usa arte original de fantasia sem personagens existentes.
